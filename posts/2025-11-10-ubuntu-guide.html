Krótki przewodnik po Ubuntu

Ubuntu to świetny wybór dla początkujących — stabilne, łatwe w instalacji i szeroko wspierane. W tym wpisie znajdziesz podstawowe kroki po instalacji i parę przydatnych poleceń.

Po instalacji

  1. Zaktualizuj system: sudo apt update && sudo apt upgrade
  2. Zainstaluj podstawowe narzędzia: sudo apt install build-essential git curl
  3. Skonfiguruj zaporę: sudo ufw enable
